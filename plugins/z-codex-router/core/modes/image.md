# Image

## 适用范围

图像生成、编辑、提示词、视觉素材检查和确定性图像批处理。

## 任务类型到 Tier

| 任务 | Tier |
| --- | --- |
| 具体提示词、参数提取或素材检查 | A0 |
| 已知目标的小幅提示词/参数调整 | A1 |
| 有界的提示词迭代或确定性批处理 | B0 |
| 一致性控制、复杂编辑或失败恢复 | B2 |
| 创意方向、参考权衡或视觉概念选择 | C1 |
| 商业/高价值素材质量或版权风险复核 | C3 |

## 检查与验收证据

确认用途、受众、尺寸、源资产、版权、交付格式和验收条件。生成 brief 应涵盖主体、构图、风格、光线、材质、颜色、镜头、用途和负向限制；实际资产需用可用工具生成或编辑，检查尺寸、格式、版权边界和目标用途。

## 环境阻塞

没有可用图像工具、源资产授权、必要参考图或交付规格时，不把文字方案称为已生成素材。
