# 视频

## 适用范围

视频/音频素材、FFmpeg 流程、编码兼容性、媒体创作和播放验证。

## 任务类型到 Tier

| 任务 | Tier |
| --- | --- |
| 字幕、shot list、参数等只读检查，或不产生持久副作用的固定命令 | A0 |
| 明确的小型媒体参数调整 | A1 |
| 有界 FFmpeg 处理或常规媒体工作流 | B0 |
| codec、container、time base、HDR、色彩、同步或平台兼容性诊断 | B2 |
| 视频系统架构或创意方向 | C1 |
| 品牌关键媒体、生产播放风险或独立复核 | C3 |

## 检查与验收证据

确认源素材、目标平台、时长、版权、交付规格、量化阈值和验证方法；量化阈值必须由目标产品/平台定义，不臆造通用数值。检查 codec/container、像素格式、色彩/HDR、time base、帧率、旋转、A/V sync/唇音同步，以及硬件编解码、GPU/CPU/内存/温度、长时稳定性和设备矩阵。以目标平台的实际播放证据验收；产出文件本身不等于兼容性证据。

## 环境阻塞

源文件、编解码器、版权授权、目标设备、播放器环境或目标平台阈值缺失时，说明无法验证的范围，不臆测播放结果。
