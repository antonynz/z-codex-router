# Research

## 适用范围

事实检索、技术调查、比较、证据评估和建议。

本 mode 只提供研究任务的映射示例；Tier 仍按 router 的统一判定轴和顺序决定。

## 任务类型到 Tier

| 任务 | Tier |
| --- | --- |
| 清晰检索、证据提取或摘要 | A0 |
| 明确范围的简短资料核验 | A1 |
| 问题、来源和停止条件明确的有界技术调查或比较 | B0 |
| 目标和评估标准已确定，但存在多来源冲突或复杂评估的深入调查 | B2 |
| 问题、目标、评估标准或关键取舍未定，需要先做研究设计或方向判断 | C1 |
| 战略、高风险或高价值独立结论复核 | C3 |

## 检查与验收证据

明确问题、时间范围、决策用途、来源要求和停止条件。优先近期、可追溯的一手或权威来源；分开已验证事实、来源限制、假设、推断、风险和建议，并标明检索日期与不确定性。

## 环境阻塞

关键来源不可访问、时效无法确认、需要的权限缺失或证据不足时，报告证据限制而不推出确定性结论。
