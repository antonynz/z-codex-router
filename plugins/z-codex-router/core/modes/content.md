# 内容

## 适用范围

面向读者的 content design/UX writing、文案、文章、技术解释、编辑、翻译和定稿。

本 mode 只提供内容任务的映射示例；Tier 仍按 router 的统一判定轴和顺序决定。

## 任务类型到 Tier

| 任务 | Tier |
| --- | --- |
| 翻译、摘要、提取或固定格式改写 | A0 |
| 明确语气的短文案或小幅润色 | A1 |
| 受众、目的、语气和事实范围明确的有界编辑或多步定稿 | B0 |
| 受众、目的和核心定位已确定的深度内容或复杂素材整合 | B2 |
| 受众、目的、核心定位或关键叙事取舍未定，需要先做定位判断 | C1 |
| 高影响发布前定稿或独立风险审核 | C3 |

## 检查与验收证据

确认受众、目的、语气、长度、事实范围、来源、交付格式、信息层级、内容模型、术语系统、localization 和跨界面一致性。验收以事实准确、引用可追溯、语气一致、可读性/可访问性测试和满足长度/格式为准；不以填充字数代替信息。

发布前核对事实、版权、肖像、音乐、赞助披露和平台政策，取得发布确认，并准备撤回预案；草案或定稿不等于已获发布批准。

## 环境阻塞

来源、版权许可、品牌规范或最终审批缺失时，明确为限制而不虚构事实或引用。
