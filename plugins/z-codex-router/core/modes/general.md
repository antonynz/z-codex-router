# General

## 适用范围

不属于其他专门 mode 的通用问答、摘要、规划、解释、提取和格式化。

本 mode 只提供通用任务的映射示例；Tier 仍按 router 的统一判定轴和顺序决定。

## 任务类型到 Tier

| 任务 | Tier |
| --- | --- |
| 已知输入的提取、分类、翻译、固定格式输出或直接事实短答 | A0 |
| 明确、小范围、低影响、可逆的局部规划、格式调整或少量重写 | A1 |
| 需求、边界和验收明确，需多步产出或跨约束整理 | B0 |
| 目标和关键取舍已确定，但跨领域需要复杂深入执行 | B2 |
| 需求、根因或关键取舍未定，需要先澄清、研究或方向判断 | C1 |
| 高影响决策或独立风险复核 | C3 |

## 检查与验收证据

确认目标、边界、受众、事实来源和输出格式；区分事实、假设、推断与建议。交付应直接满足请求，并列出改变结果的假设和未验证限制。

## 环境阻塞

缺少必要上下文、权限、来源或可验证输入时停止并说明，不能以更高 tier 代替。
