# Z Codex Router

Z Codex Router is an open-source, local-only routing policy plugin for Codex. It supplies a safe Enable action, a Doctor, controlled upgrade and recovery paths, and a clean uninstall sequence. It is not an OpenAI product and has not been reviewed or listed by OpenAI.

The plugin keeps task classification separate from model profiles, preserves user-managed `AGENTS.md` content, and fails closed when it cannot safely verify state.

See the repository README for development and release details.
